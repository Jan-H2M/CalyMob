## Candidate

Reuse the existing Gonflage-only predicate and authorize from the caller's member
document in the requested club before reading loan, bank or recipient details.
Both callables share this context loader. Client fields and auth-token role
claims cannot grant access. An admin with a Gonflage badge still qualifies.

The callable-level tests cover both endpoints, every extra live role, malformed
badges, unauthenticated requests, cross-club access, forged client/token roles,
accepted badge aliases and a successful mail path with a mocked transport.
Denied requests perform no loan/bank reads, QR generation, mail, logging or writes.
The dedicated GitHub workflow runs these tests for PRs into `dev` and `main`.
