# MOB-036 — Apnée roster in pool organization

## Superseded behavior (2026-10-16)

The pool detail screen previously rendered scuba-oriented organization only,
even when the session already had planned A1/A2 apnée lessons. That omission is
superseded.

## DEV behavior

- Non-theory pool sessions show the planned apnée lessons by track and hour,
  with theme, instructors, and students.
- The roster stream is created once for the screen instead of during rebuilds.
- Names are resolved by exact member ID from the privacy-safe
  `member_directory` projection; the app does not read other members' private
  source documents.
- The section is explicitly labelled as a planned roster. It never infers
  attendance, QR proof, exercise validation, or an official result.
- The CalyMob rules mirror now includes the canonical CalyCompta rule that
  allows members to read `apnee_lessons` while denying all client writes.

## Verification

Widget coverage checks parsing, A1 labels, named roster rendering, the
attendance disclaimer, and the empty state. Manual DEV testing should compare
one session with planned apnée lessons and one without them.

No production deploy or store release is part of this change.
