# COM-065 — numéro de plongée provisoire

Date: 2026-08-31. Run: `fix-COM065-20260831`.

## Avant / diagnostic

Le formulaire affichait max(numéros existants)+1 comme « N° PLONGÉE », sans
indiquer son caractère provisoire. La création omet volontairement cette valeur
automatique; le serveur attribue max(compteur.next, maxExistant+1). La différence
est démontrée dans le code, pas reproduite sur les données de la personne signalée.

## Après / périmètre

Le champ automatique affiche « N° PROVISOIRE » et une explication pleine largeur
indique que le numéro définitif peut différer après enregistrement. L'aperçu de
dictée ajoute « (provisoire) ». Saisir un numéro manuellement retire immédiatement
cette indication. L'allocation atomique, les numéros historiques manuels et le
refus des doublons exacts sont inchangés.

Il s'agit d'une mitigation de l'affichage trompeur, pas d'une réparation des
compteurs personnels ni d'une preuve que tous les symptômes signalés sont résolus.
Aucun changement de Cloud Function, règle, version ou donnée de production.
